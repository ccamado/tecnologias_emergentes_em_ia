🔬 Ferramentas de Visão Computacional — OpenCV, YOLO e Detectron2

📅 12/05/2026 (Segunda-feira) · EE Manoel Bonifácio Nunes da Cunha

📖 Introdução
Existem ferramentas incríveis que tornam a Visão Computacional acessível para desenvolvedores. Nesta aula conhecemos três das mais famosas: OpenCV, YOLO e Detectron2. Não vamos programar — o objetivo é entender o que cada uma faz e imaginar como poderiam ser usadas na nossa escola.
🎯 Conteúdo da Aula
📦
OpenCV — Biblioteca de Visão Computacional
Open Source Computer Vision Library. Ajuda a manipular, processar e analisar imagens. É como uma caixa de ferramentas para trabalhar com imagens digitais.
⚡
YOLO — Detecção em Tempo Real
'You Only Look Once'. Famoso pela velocidade. Detecta múltiplos objetos em uma imagem em uma única passagem. Usado em câmeras de vigilância e carros autônomos.
🔍
Detectron2 — Reconhecimento Detalhado
Desenvolvido pelo Facebook AI. Reconhece e segmenta objetos com mais detalhamento. Identifica não só o que é, mas onde exatamente está na imagem.
🏫
Biblioteca vs Aplicação
Biblioteca é um conjunto de código pronto para usar. Aplicação é o produto final que o usuário utiliza. OpenCV, YOLO e Detectron2 são bibliotecas — ferramentas para criar aplicações.
🗂️
Escolhendo a Ferramenta Certa
OpenCV para manipulação geral; YOLO para detecção rápida; Detectron2 para análise detalhada. Cada uma tem sua especialidade.
